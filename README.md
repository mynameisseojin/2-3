# 머먹지?

> 뭐 먹을지 막막하지..? 그럴 땐 머먹지!

냉장고에 남아 있는 재료와 식사 조건을 입력하면 AI가 만들 수 있는 요리와 상세 레시피를 추천해주는 웹 서비스입니다.

## 배포 URL

https://2-3-alpha.vercel.app/

## 서비스 소개

매일 반복되는 메뉴 고민을 줄이고, 냉장고 속 남은 재료를 활용할 수 있도록 돕는 AI 요리 추천 서비스입니다.

사용자는 보유 재료, 식사 인원, 요리 장르, 원하는 조리 시간, 추가 요청을 입력할 수 있습니다. 입력된 정보는 Gemini AI가 분석하여 맞춤 요리와 조리법으로 반환합니다.

## 주요 기능

- 냉장고 속 보유 재료 입력
- 식사 인원 선택
- 요리 장르 선택
- 원하는 조리 시간 선택
- 추가 요청 입력
- Gemini AI 기반 요리 추천
- 추천 요리의 재료 목록 출력
- 단계별 조리 방법 출력
- 예상 조리 시간 및 난이도 표시
- 대체 재료와 요리 팁 제공
- 빈 입력 오류 안내
- API 오류 안내
- 응답 지연 및 타임아웃 안내
- 데스크톱·모바일 반응형 화면 지원

## 페이지 및 섹션 구성

### 1. 홈

- 서비스명과 슬로건 소개
- 대표 추천 메뉴 예시
- AI 요리 추천 화면으로 이동하는 버튼
- 서비스 이용 방법 안내

### 2. AI 추천

사용자가 다음 정보를 입력합니다.

- 보유 재료
- 식사 인원
- 요리 장르
- 원하는 조리 시간
- 추가 요청

입력한 내용은 Vercel Serverless Function을 통해 Gemini API로 전달됩니다.

### 3. 서비스 소개

- 서비스 제작 목적
- 식재료 낭비 감소 효과
- 메뉴 고민 시간 절약
- 주요 타겟 사용자 소개
